# 📝To-do App

A simple and responsive task management web application built using **HTML, CSS, and JavaScript**.  
It helps users organize daily tasks efficiently with an easy-to-use interface.

## 🚀 Live Demo
https://to-do-app-gamma-dun.vercel.app/

## ✨ Features
- ➕ Add new tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as completed  
- 🔍 Filter tasks  
- 📱 Responsive design for mobile and desktop

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript(ES6)  
- Vercel(Deployment)
